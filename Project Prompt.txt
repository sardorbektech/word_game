Ha, javoblaringiz asosida loyiha konsepsiyasi ancha aniq bo‘ldi. Quyida men avval **bitta muhim texnik muammoni** tuzatib olaman, keyin siz so‘ragan **asosiy arxitektura va o‘yin jarayoni**ni AI coding agentga berishga tayyor formatda yozaman.

> **Muhim:** siz tanlagan `GPT-5.6 Luna` hozir OpenAI API’da mavjud va uning API model ID'si `gpt-5.6-luna`. U yuqori hajmdagi, xarajatga sezgir workloadlar uchun mo‘ljallangan. ([OpenAI Developers][1])

## 1. Netlify + SQLite bo‘yicha muhim tuzatish

Siz:

* Frontend → Netlify
* Backend → FastAPI
* Database → SQLite
* hammasi Netlify

deb belgiladingiz.

Bu yerda **SQLite bilan persistent production database muammosi bor**. Netlify serverless funksiyalari doimiy server kabi ishlamaydi. SQLite fayliga yozilgan ma'lumot keyingi invocation'da ishonchli saqlanib qolmasligi mumkin.

Shuning uchun men arxitekturani quyidagicha qurishni tavsiya qilaman:

```text
                    USER
                     │
                     ▼
             ┌────────────────┐
             │    Netlify     │
             │ Static Frontend│
             └───────┬────────┘
                     │ HTTPS
                     ▼
             ┌────────────────┐
             │ Netlify        │
             │ Functions      │
             │ / FastAPI      │
             └───────┬────────┘
                     │
          ┌──────────┴──────────┐
          ▼                     ▼
   ┌──────────────┐      ┌──────────────┐
   │ Persistent DB│      │  OpenAI API  │
   │              │      │ GPT-5.6 Luna │
   └──────────────┘      └──────────────┘
```

Agar **SQLite aynan shart** bo‘lsa, production backendni doimiy serverga chiqarish kerak.

Agar **Netlify 100% shart** bo‘lsa, SQLite o‘rniga SQLite-compatible persistent database ishlatish kerak bo‘ladi. Men promptda buni alohida **architecture constraint** sifatida qoldirgan bo‘lardim.

# 2. Loyiha konsepsiyasi

Loyiha oddiy vocabulary game emas.

Bu:

> **Adaptive English Sentence Reconstruction Game**

bo‘ladi.

Foydalanuvchi o‘zbekcha gapni ko‘radi va uning inglizcha tarjimasini **grammatik jihatdan to‘g‘ri ketma-ketlikda** pastdagi harflar/kataklar orqali yig‘adi.

Masalan:

```text
O'zbekcha:

Men har kuni universitetga boraman.
```

Pastdagi matrix:

```text
┌────┬────┬────┬────┐
│ go │ I  │ day│ to │
├────┼────┼────┼────┤
│every│university│am│
├────┼────┼────┼────┤
│morning│the│go │
└────┴────┴────┴────┘
```

Foydalanuvchi:

```text
I → go → to → university → every → day
```

deb tanlashi kerak.

Agar:

```text
I → to
```

qilsa, **darhol xato**.

Sababi bu o‘yinda faqat so‘zlarni bilish emas, **English grammatical order** ham o‘rgatiladi.
